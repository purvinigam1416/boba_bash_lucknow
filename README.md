# 🌶️ Kurkure Club — Boba Bash Lucknow

**Life Needs More Crunch!**

Kurkure Club is a fun, colourful landing page created for Boba Bash Lucknow. The website uses bold text, spicy colours and a Kurkure-themed background to create an energetic and creative experience.

## 🌟 Features

- Attractive Kurkure-themed landing page
- Bold typography and yellow-orange colour scheme
- Background image with a dark overlay
- Animated badge
- About section with creative artwork
- Hover effects on the button and feature labels
- Responsive layout for mobile screens
- Smooth scrolling between sections

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, animations and responsive design
- **GitHub Pages** — Website hosting

## 📂 Project Structure

```text
boba_bash_lucknow/
├── index.html
├── style.css
├── kurkure.jpg
└── README.md
```

## 🚀 Run the Project Locally

1. Download or clone this repository.
2. Keep `index.html`, `style.css` and `kurkure.jpg` in the same folder.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.
